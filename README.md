# Оркестр «Метелица»

Новый сайт Государственного оркестра русских народных инструментов «Метелица».

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run lint
npm run build
npm run test:e2e
```

Шрифт интерфейса — `public/fonts/NAMU-1850.otf` (NAMU 1850, Regular). Заголовки — Prata.

## Откуда взяты тексты и картинки

Факты, афиша и контакты сверены с https://metelitsa-spb.ru/. Композиция главной повторяет приложенный кадр 1440. Отдельного файла Figma и вырезанного коллажа в папке не было: рама и орнамент собраны из штриховой графики и фотографий оркестра с исходного сайта.
