# Оркестр «Метелица»

Новый сайт Государственного оркестра русских народных инструментов «Метелица».

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run lint
npm run build
npm run test:e2e
```

Шрифт интерфейса — `public/fonts/NAMU-1850.otf` (NAMU 1850, Regular). Заголовки — Prata.

## Откуда взяты тексты и картинки

Факты, афиша и контакты сверены с https://metelitsa-spb.ru/. Страницы собраны по кадрам Figma 1440 и 390: шапка (восемь разделов и кнопка «Афиша»), герой, факты, программы, оркестр, анонсы, медиа, приглашение и подвал. Серебряная рама и вырезанная солистка лежат в `public/images/frame.png` и `public/images/soloist.png`. Логотипы партнёров скачаны из блока «Наши партнёры» на metelitsa-spb.ru и идут отдельной лентой перед подвалом. Знак в шапке — `public/brand/logo.svg`.
